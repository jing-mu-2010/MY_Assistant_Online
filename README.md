# PathPal 途途智能语音助手交付说明

## 1. 产品简介

本设备基于 ESP32-S3 BOX1 开发板实现，是一款面向大学生场景的智能语音助手。设备可通过语音唤醒、录音识别、LLM 问答和语音播报完成自然语言交互。


## 2. 交付内容

- ESP32-S3 BOX1 固件工程
- 屏幕 UI 显示界面
- Wi-Fi 手机配网页面
- 语音唤醒与实时语音问答流程
- 按键预设语音播放功能
- 音量调节与静音控制功能

## 3. 设备启动

1. 使用 USB 线给设备供电。
2. 设备上电后会自动启动系统。
3. 若已配置过 Wi-Fi，设备会自动连接已保存的网络。
4. 若未配置 Wi-Fi，屏幕会进入配网提示界面。

设备正常工作需要可访问互联网的 2.4 GHz Wi-Fi 网络。

## 4. 手机配网

首次使用或更换网络时，请按以下步骤配置：

1. 打开手机 Wi-Fi 设置。
2. 连接设备热点：
   - 热点名称：`BOX1-SETUP`
   - 热点密码：`12345678`
3. 手机浏览器打开：
   - `http://192.168.4.1`
4. 在页面中填写：
   - `Wi-Fi SSID`：目标 Wi-Fi 名称
   - `Wi-Fi Password`：目标 Wi-Fi 密码
   - 'key'：key留空即可，apikey已经写入文件当中，勿删。
5. 点击 `Save and Connect`。
6. 保存后，手机切回正常 Wi-Fi，等待设备自动连接网络。

说明：Wi-Fi 与 Key 会保存到设备内部，断电重启后无需重复配置。

## 5. 语音交互

1. 对设备说唤醒词：`Alexa`。
2. 屏幕进入 Listening/聆听状态后，说出问题。
3. 设备识别语音后，会请求 LLM 生成回答。
4. 回答生成后，设备会显示文字并进行语音播报。

当前固件已做播放保护：一旦 LLM 开始播报，设备会优先完整念完当前回答，不会被唤醒词、按键、提示音或环境声音打断，也不会在播报过程中切回 Listening 界面。

## 6. 按键说明

| 按键 | 功能 |
| --- | --- |
| `K0 / Config` | 单击播放预设介绍语音 |
| `K1` | 短按降低音量 |
| `K1` | 长按切换静音/取消静音 |
| `K2` | 短按提高音量 |
| `RST` | 重启设备 |
| `BOOT` | 烧录/下载模式使用，正常使用时不需要按 |

注意：设备正在播报 LLM 回答时，`K0 / Config` 会被暂时忽略，避免打断当前语音。

## 7. 当前固件状态

当前交付固件包含以下修正：

- 屏幕颜色配置已调整为当前屏幕适配值。
- 按键预设语音文件使用 `/spiffs/config_voice.wav`。
- 单声道 WAV 播放时会自动转为双声道输出，避免语音播放速度异常。
- TTS 播放时加入音频保护，避免播报被识别任务或按键插断。
- Wi-Fi 可通过手机热点/浏览器页面配置，无需每次连接电脑。

## 8. 常见问题

### 8.1 设备无法回答

请检查：

- Wi-Fi 是否连接成功。
- 手机/路由器网络是否能访问互联网。
- OpenAI API Key 是否填写正确。
- Key 是否仍有额度、是否被禁用。

### 8.2 可以显示文字但没有声音

请检查：

- 是否处于静音状态。
- 音量是否过低，可短按 `K2` 增大音量。
- 喇叭排线和功放连接是否正常。

### 8.3 唤醒词无反应

请检查：

- 是否已连接 Wi-Fi。
- 周围环境是否过吵。
- 说唤醒词时请靠近设备正面。
- 若仍无反应，可按 `RST` 重启设备。

### 8.4 重新配网

设备会持续开放 `BOX1-SETUP` 配网热点。需要更换 Wi-Fi 或 Key 时，重新连接该热点并访问 `http://192.168.4.1` 修改保存即可。

### 8.5 屏幕颜色异常

当前固件已按实际屏幕表现设置颜色字节序。如果更换不同批次屏幕出现颜色异常，需要重新适配 LCD 颜色配置。

## 9. 使用注意事项

- 建议使用稳定的 2.4 GHz Wi-Fi。
- 不建议在强噪声环境下进行语音交互。
- API Key 属于敏感信息，请由甲方自行保管。
- 设备回答质量与网络状态、语音识别效果、Key 对应服务状态有关。
- 正常使用时只需供电，无需连接电脑。
